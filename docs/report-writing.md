# 리포트 문장 기준

“지금 가진 강점이 어떤 작은 프로젝트에서 어떻게 빛날 수 있나요?”에 답합니다.

## 추천 대상

직업, 취업, 대행 업무가 아니라 사용자가 직접 운영할 수 있는 콘텐츠·계정·연재·작은 모임·자료집을 제안합니다. 관심사와 경험에서 출발해 6개월 안에 첫 콘텐츠나 작은 운영 모습을 그릴 수 있는 크기로 잡습니다. 6개월은 규모를 가늠하는 내부 기준이며 기한이나 취업 목표로 강조하지 않습니다.

주제와 형태가 함께 보이는 이름을 씁니다. “카드뉴스 계정”에서 끝내지 않고 “동네 책방을 소개하는 카드뉴스 계정”처럼 무엇을 보여줄지 드러냅니다. 세 제안은 답변에 맞춰 서로 다른 가치나 표현 방식을 갖게 합니다.

예:

- 동네 책방을 소개하는 카드뉴스 계정
- 책 속 문장과 표지 색감을 모으는 취향 계정
- 한 달에 한 권을 함께 나누는 작은 독서모임
- 생활 속 궁금증을 쉽게 풀어주는 짧은 글 연재
- 직접 만든 소품과 만드는 과정을 담는 기록 계정
- 나만의 정리 양식을 나누는 작은 자료집

예시는 사용자 관심사와 맞을 때만 씁니다. 모든 사람에게 같은 카드뉴스 계정을 추천하지 않습니다.

## 문장과 구성

쉬운 말과 짧은 문장으로, 읽는 사람을 “당신은”으로 부릅니다. “사용자는”, “응답자는” 같은 3인칭 표현을 쓰지 않습니다.

각 아이디어는 서로 다른 서술형 답변 최소 두 개와 실제 대표·보조 성향 하나를 연결합니다. 예를 들어 빈티지 장비 관심 + 중고 거래 + 리뷰·협찬 경험 + 탐험가 성향은 “빈티지 다이빙 장비를 소개하고 소량 판매하는 계정”으로 이어질 수 있습니다. 입력하지 않은 재고나 자본은 가정하지 않습니다. 세 아이디어에 답변을 하나씩 배분하지 않습니다.

직접 쌓은 경험에는 사용자가 실제로 했다고 적은 행동만 넣습니다. “릴스를 본다”는 시청이지 “사진 분석 능력”이 아닙니다. 관심과 소비, 직접 실행한 경험을 구분하고 중고 거래·운영·리뷰·협찬 등 이미 해본 행동을 빠뜨리지 않습니다. 확인할 행동이 없으면 경험 목록은 비워둡니다.

거래·제작·운영·협찬 경험이 구체적으로 명시돼 있다면 작은 판매나 유료 결과물 등으로 연결되는 프로젝트를 최소 하나 제안합니다. 숙련된 사람에게 입문 기록과 팁 공유만 반복하지 않지만, 경험 없는 사람에게 수익화를 강요하거나 수익을 보장하지도 않습니다.

각 원문 인용은 핵심 구절 하나를 60자 이내(가급적 10~30자)로 발췌합니다. 아이디어마다 연결한 성향과 각 인용의 원래 질문 번호를 표시하고, 건너뛴 답변은 인용하지 않습니다. 각 제안에는 강점과의 연결, 그 강점이 콘텐츠나 모임에서 빛나는 장면, 현재 가지고 있는 소재로 이어질 수 있는 이유, 답변 원문 근거를 담습니다.

> 동네 책방을 소개하는 카드뉴스 계정에서 강점이 빛날 수 있어요. 책과 공간의 작은 차이를 알아보는 시선은 장소마다 다른 매력을 짧고 친근하게 전하는 데 도움이 될 수 있어요. 직접 읽은 책과 방문한 공간이 있다면 나만의 소개에 담을 소재가 될 수 있어요.

“하세요”, “해야 합니다” 같은 지시, 학습 계획, 체크리스트, 이번 주 숙제를 넣지 않습니다. 마무리도 나만의 콘텐츠·프로젝트가 만들어내는 장면과 가치를 설명합니다.

## 피할 제안

- 콘텐츠 마케터, 디자인 보조 같은 직무명
- 고객 확보가 전제인 가게 SNS 운영 대행
- 큰 자본이나 자격·긴 수련이 필요한 창업·전문직
- “6개월 뒤 취업할 수 있어요” 같은 취업·수입·성공 보장
- 근거 없이 전문성이나 많은 팔로워를 가정하는 표현

서버는 JSON 구조, 서로 다른 답변 두 개 이상의 짧은 원문 인용, 실제 대표·보조 성향과의 연결을 검사합니다. 쉬운 정도와 프로젝트 규모는 모델 작성 지침이며 자동 사실 검증을 보장하지 않습니다.
