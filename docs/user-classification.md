# SUMUP 사용자 분류 v2

이 분류는 현재 7개 질문을 이용한 서비스용 자기 탐색 가설입니다. 검증된 심리 척도나 능력 평가가 아니며, 직업 적합성을 단정하지 않습니다.

## 8가지 대표 성향

| 유형 | 구분하는 욕구·행동 | 강점이 담길 수 있는 프로젝트 |
| --- | --- | --- |
| 탐험가 | 새로운 경험, 자유로운 방법, 변화 | 동네 장소를 소개하는 카드뉴스 계정 |
| 취향 수집가 | 감각적인 발견, 좋아하는 것, 개성 | 색과 공간을 모으는 취향 계정 |
| 창작가 | 직접 만들기, 상상, 구체화 | 직접 만든 소품과 과정을 담는 계정 |
| 탐구가 | 지식, 관찰, 논리, 깊은 이해 | 생활 속 궁금증을 설명하는 카드뉴스 연재 |
| 연결가 | 공감, 관계, 협업, 기여 | 좋아하는 주제로 이야기를 나누는 작은 모임 |
| 표현가 | 말·글로 표현, 이야기 전달 | 일상의 생각을 나누는 짧은 글 연재 |
| 설계가 | 계획, 정리, 안정, 책임감 | 정리 양식과 일정표를 나누는 계정 |
| 성장가 | 배우기, 연습, 숙련, 발전 | 관심 활동을 익혀가는 성장 기록 계정 |

## 질문별 역할

1. 흥미의 시작: 무엇에 마음이 끌리는가
2. 선호 활동: 어떤 방식이 잘 맞는가
3. 가치관: 무엇을 중요하게 여기는가
4. 일상 선호: 어떤 하루가 좋은가
5. 삶의 방향: 앞으로 무엇을 바라는가
6. 인식한 재능: 스스로 어떤 강점이 있다고 보는가
7. 환경: 어떤 조건에서 능률이 높아지는가

53개 선택지 모두 `classification.js`의 ANSWER_MAP에 연결합니다. 각 선택은 주성향 3점, 보조성향 1점을 줍니다. 질문 가중치는 동일합니다. 유형마다 등장 횟수가 달라 단순 합계만 비교하면 편향되므로, 유형별로 각 질문에서 얻을 수 있는 최대 점수의 합으로 나눕니다. 화면의 0–100 점수는 이 최대치에 대한 답변 단서의 상대적 정도입니다. 확률, 인구 백분위, 능력 점수가 아니며 전체 합이 100일 필요도 없습니다.

반올림 전 정규화 점수로 대표·보조 성향을 결정합니다. 동점이면 Q5(원하는 삶), Q3(가치관), Q1, Q2, Q4, Q6, Q7에서 해당 선택이 준 점수를 순서대로 비교합니다. 모두 같으면 정의된 유형 순서를 사용합니다. 두 성향의 정규화 점수 차이가 0.08 이하면 두 성향이 비슷하다는 문구를 표시합니다.

8개 대표 유형과 서로 다른 보조 유형으로 최대 56개 조합을 표현할 수 있습니다. 답변 조합마다 대표 유형을 억지로 바꾸지는 않습니다. 대표 유형이 같아도 결과 본문의 해석은 7개 답변 모두를 반영합니다.

- 요약 태그: Q1·Q2·Q4·Q7
- 강점 설명: Q2·Q6
- 동기 설명: Q3·Q5
- 지향 설명: Q4·Q7
- 강점 활용 분야: 대표 성향별 작은 프로젝트와 강점이 드러나는 장면 + Q7 선호 환경
- 보조 성향 설명과 8개 성향 지도

서로 다른 답변 조합은 본문에 최소 한 가지 다른 해석이 나타납니다. 동일 입력은 언제나 동일 결과를 반환합니다. 이름은 분류 점수에 사용하지 않습니다. 답변 코드는 구분용이며 심리적 의미를 부여하지 않습니다.

## 검증과 개선

`npm test`는 8가지 대표 응답, 53개 선택지의 점수·본문 반영, 10,000개 재현 가능한 응답 조합, 잘못된 입력 거부를 확인합니다. 실제 사용자 유형의 분포나 심리적 타당성을 검증하는 테스트는 아닙니다. 추후 실제 사용자 피드백으로 문항 해석·유형 분포·동점 빈도를 확인한 뒤 분류 가설을 조정해야 합니다.
