# SUMUP

모바일 중심 자기 탐색 웹. 이름 입력 → 선택형 7문항 → 서술형 3문항 → 기본 성향 결과와 AI 리포트로 이어집니다.

## 로컬 실행

Node.js 24 권장.

```sh
npm ci
cp .env.example .env.local
# .env.local에 본인의 OPENAI_API_KEY를 안전하게 설정
npm run dev
```

기존 키 파일을 덮어쓰지 마세요. `.env.local` 수정 후 개발 서버를 다시 시작하세요. 개발 서버와 `npm run preview` 모두 `/api/report`를 처리합니다.

- `npm test`: 성향 분류, 서버 입력·출력 검증, 오류·인용 근거·요청 제한 테스트
- `npm run build`: 프로덕션 프런트엔드 빌드
- `docs/user-classification.md`: 8가지 성향의 분류 기준

## Vercel 배포

GitHub 저장소의 `main`을 Vercel에 연결합니다. Framework는 Vite, Build Command는 `npm run build`, Output Directory는 `dist`입니다. `api/report.js`는 Vercel Node Function으로 배포됩니다.

Vercel 프로젝트 Settings → Environment Variables에서 서버용 `OPENAI_API_KEY`를 등록하세요. 이미 있다면 중복 등록할 필요 없습니다. 실제 사용할 Production 또는 Preview 환경에 체크하고, 키를 등록하거나 변경한 후에는 해당 환경을 Redeploy 해야 합니다. 키는 Git, 채팅, `VITE_`로 시작하는 변수에 넣지 마세요.

`OPENAI_MODEL`은 선택 사항이며 기본값은 `gpt-4.1-mini`입니다. 클라우드 프록시 환경처럼 OPENAI_ 변수명을 쓸 수 없는 곳에서는 서버용 `SUMUP_AI_API_KEY` 별칭을 지원합니다. Vercel에만 등록한 값은 로컬 개발 환경에 자동으로 주입되지 않습니다.

GitHub Pages는 정적 기본 테스트만 제공하며 AI Function을 실행할 수 없습니다. AI 리포트는 Vercel 또는 서버 API를 제공하는 Vite 개발 환경에서 사용하세요.

## AI 리포트와 데이터 흐름

이름은 API에 전송하지 않습니다. 리포트 만들기를 누르면 선택형 답변 7개와 서술형 답변 3개가 같은 사이트의 `/api/report`로 전송됩니다. 서버가 성향을 다시 계산한 뒤, 그 해석과 서술형 답변을 OpenAI Responses API에 보냅니다. 키는 서버에서만 사용하며, OpenAI 요청에는 `store: false`를 지정합니다. 이는 제공자의 전체 보관 정책을 대체하는 보장이 아닙니다.

구조화된 응답의 형태와 각 제안의 원문 인용을 서버에서 확인합니다. 모델이 입력에 없는 인용문을 만들거나 불완전한 응답을 반환하면 성공 리포트로 표시하지 않습니다. AI와 사용자 텍스트는 화면에서 HTML로 실행되지 않도록 이스케이프합니다.

리포트에는 현재 관심사 요약, 키워드, 축적한 자산, 6개월 안에 작은 규모로 시작할 만한 일 3개, 강점이 빛나는 구체적인 장면, 현재 경험과 연결되는 이유, 답변 원문 근거이 포함됩니다. 실패 시 입력을 유지하고 재시도할 수 있으며 기본 성향 결과는 API 없이도 볼 수 있습니다. 답변을 수정하면 이전 AI 리포트는 무효화됩니다. 생성 취소나 화면 이동 뒤 도착한 응답은 화면에 반영하지 않습니다.

서술형 답변과 AI 리포트는 메모리에만 있으며 새로고침하면 사라집니다. 기존 꾹 눌러 저장 기능은 기본 성향 결과만 브라우저에 저장합니다. 서버는 답변·키·공급자 오류 본문을 로그로 출력하지 않습니다.

## 운영 확인

키가 설정된 Vercel 배포에서 7개 문항과 서술형 3개를 작성한 뒤 리포트를 생성해 실제 요청을 확인하세요. 세 방향의 인용문이 본인의 답변과 일치하고 강점이 도움이 되는 장면과 현실적인 역할 범위가 표시되는지 확인합니다. 빌드나 모의 API 테스트 통과만으로 실제 API 연결을 검증한 것은 아닙니다.

API는 입력당 서술형 5~1,500자, 전체 요청 20KB, 모델 호출 45초로 제한합니다. 서버 인스턴스별 IP당 15분에 5회 제한은 보조 수단입니다. 여러 인스턴스에 걸친 공통 제한이나 사용자 인증은 제공하지 않으므로, 공개 서비스의 사용량 통제는 Vercel 게이트웨이·방화벽과 OpenAI 프로젝트 예산으로 별도 설정해야 합니다.

리포트의 문장 기준은 `docs/report-writing.md`에 있습니다. 쉬운 말로 현재 강점이 실제 일에서 쓰이는 모습을 설명하고, 할 일 목록이나 장기 직업 전망으로 대체하지 않습니다.
